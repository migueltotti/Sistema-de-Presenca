Placa LED LCD1602: https://docs.wokwi.com/parts/wokwi-lcd1602

- Primeiros 4 bits baixos (D7,D6,D5,D4)
- Faço uma rotação a direita, passando os bits para (D3,D2,D1,D0)
- Passo os proximos 4 bits

| | | |
7 6 5 4 3 2 1 0
0 1 0 1 x x x x

> > > >
	| | | |
7 6 5 4 3 2 1 0
x x x x 0 1 0 1

7 6 5 4 3 2 1 0
0 0 1 1 0 1 0 1

Pino RW com nivel lógico baixo serve para escrever dados na placa, nivel alto lê da placa

Pino V0 serve para opacidade e funciona mto bem com potenciometro

Pinos A e K são para back-light

NVS (Non-Volatil Storage) para armazenar o id da relação Disciplina-Aluno em casos de falta de energia ou algo do tipo, para não resetar tudo.

Libs <WiFi.h>, <HTTPClient.h> para fazer requisições http inseguras. Usar <WiFiClientSecure.h> em conjunto das 2 anteriores para https. <ArduinoJson.h> para desserializar a resposta da API (se retornar json) e acessar como se fosse um dicionário.

Libs nativas do ESP32:
<WiFi.h>
<HTTPClient.h>
<WiFiClientSecure.h>

Libs instaladas no Library Manager:
<ArduinoJson.h>
